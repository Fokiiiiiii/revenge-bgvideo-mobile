# v1.0.14

チャンネル一覧の背景を実機のFiberとnative layoutで特定しました。`flex:1`の画面だけでなく、四辺が0のabsolute配置で画面を覆う背景にも透過を適用します。

チャンネル一覧、一覧の上部、画面下部のバーについては、確認した4種類の専用コンポーネントの描画結果を処理します。後の再描画で不透明な色に戻ることを避けます。Revengeのimport path探索を使い、Metro IDは固定していません。

ClearVisionがある場合は、カスタムCSSの `--background-shading` を動画全体の上に1枚、`--card-shading` と `--input-shading` を上部・下部のパネルに適用します。ClearVisionがなくても動画は再生できます。BgVideo側でカード・入力欄・モーダルのテーマ色を一律に消す処理を縮小し、背景を覆う6種類の基本トークンへ限定しました。

38 tests / 264 assertions、型チェックとビルドを確認。CSS変更、パネルの再描画、OFFと停止時の復元をテストしています。配布版を入れた後の全画面表示は別途実機確認が必要です。

HTTPSのローカルキャッシュ、長時間の描画負荷、任意のDiscord更新への互換性は未解決または未検証です。診断接続は端末内の作業用markerがある場合にだけ有効になります。
